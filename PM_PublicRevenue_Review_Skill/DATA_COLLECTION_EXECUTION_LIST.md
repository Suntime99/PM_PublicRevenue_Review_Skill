## 采集规范

### 每个文件必须包含的元数据头

```markdown
# {法规名称}

- **来源**: {官方网址}
- **文号**: {如适用}
- **通过日期**: YYYY-MM-DD
- **施行日期**: YYYY-MM-DD
- **最新修正**: YYYY-MM-DD 或 无
- **时效状态**: ✅ 现行有效 / ⚠️ 征求意见稿 / ❌ 已废止
- **关联条款**: {与公共收益相关的条款号}
- **审查应用**: {适用模块 P1-P13}
```

### 文件命名规范

```
# 国家级
{法规名称}_{版本号或年份}.txt

# 省级
{省份}_{条例/办法名称}_{年份}.txt

# 城市级
{城市}_{条例/办法名称}_{年份}.txt
```

## 验收标准

每个文件采集完成后，必须满足以下验收标准：

### 国家级法律/法规
- [ ] 文件行数 ≥ 500行（民法典全文应≥3000行）
- [ ] 包含所有目标条款的原文（不能只有条款号没有内容）
- [ ] 包含元数据头（来源、文号、施行日期、时效状态）

### 省级条例
- [ ] 包含公共收益归属条款的原文
- [ ] 包含管理成本上限条款（如有）的原文
- [ ] 包含公示频次条款的原文
- [ ] 包含共管账户条款的原文（如有）
- [ ] 标注条文号

### 城市级细则
- [ ] 包含公共收益相关条款的原文
- [ ] 标注条文号
- [ ] 标注施行日期

### 案例库
- [ ] 每个案例包含：案名、案号、审理法院、年份、裁判要旨、核心规则、适用模块
- [ ] 标注法规依据
