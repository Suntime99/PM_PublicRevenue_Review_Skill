# 物业公共收益审查专家 — CAP能力矩阵

> 版本：v1.0 | 更新日期：2026-10-11
> 本文件定义公共收益审查SKILL的四层能力架构与核心能力（CAP-PR-XX）。
> 设计参照：物业税务专家四层CAP架构 + 合同审阅/财务解读专家KB+CAP改造经验。

---

## 一、整体架构

```
Layer D: 报告与应对层（CAP-PR-26~30）→ 输出：审计报告六件套 / 弱点分析 / 整改建议
Layer C: 风险识别层（CAP-PR-14~25）→ 输出：风险清单 / 分级判定 / 合规示范项
Layer B: 业务审查层（CAP-PR-04~13）→ 输出：审查专项结论 / 分成台账 / 资源台账
Layer A: 场景识别层（CAP-PR-01~03）→ 输出：审查路径 / 法规集 / 历史阶段分类
                         ↓
               KB-PR-01~14 知识库（统一数据源）
```
