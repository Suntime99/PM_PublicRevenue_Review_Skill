# SKILL协作登记 — 物业公共收益审查专家

> 版本：v1.0 | 更新日期：2026-10-11
> 本文件登记本SKILL与其他SKILL的分工与协作方式，供Agent自动路由。
> 与合同审阅SKILL的分工详见 `trigger-boundary.md`。

---

## 一、协作对象总览

| 协作SKILL | 协作类型 | 触发场景 | 输出/输入 |
|-----------|:--------:|---------|---------|
| **物业服务合同审阅专家** | 串联 | 合同已签署，需核实公共收益实际执行情况 | 合同条款审查 → 执行审计 |
| **物业税务专家** | 串联 | 公共收益税务处理深度核查（七税种） | 收益分类 → 税种匹配 → 风险扫描 |
| **物业能耗专家** | 补充 | 公共能耗分摊收益归属审查 | 能耗数据 → 公共收益核查 |
| **物业财务解读与分析专家** | 串联 | 公共收益分成台账财务分析 | 分成数据 → 财务分析 |
| **物业停车场经营专家（待建）** | 补充 | 停车场收益分成/经营权审查 | 停车场收益 → 公共收益审计 |

## 二、与合同审阅专家的协作

| 情况 | 由谁处理 |
|------|---------|
| 合同尚未签署，审阅条款是否合法 | 合同审阅专家 |
| 合同已经签署，审查实际执行是否合规 | **本SKILL** |
| 合同条款有问题，需审查其实际影响 | 先合同审阅专家审条款，再本SKILL审执行 |
| 合同完全没有公共收益条款，但存在实际业务 | 本SKILL（"无合同审资源"路径） |

## 三、与税务专家的协作

### 触发场景

| 公共收益类型 | 税务专家输出 | 本SKILL如何使用 |
|------------|------------|----------------|
| 广告位出租收入 | 增值税9%+房产税12%+印花税0.1‰ | 判断公共收益漏税风险（E-05） |
| 停车场租金收入 | 房产税12%/增值税6%/9%计算 | 判断停车收益税务合规 |
| 快递柜/售货机场地费 | 增值税6%+企业所得税 | 判断收益分类是否正确 |
| 物业用房出租 | 房产税从租计征12% | 判断税务处理合规 |
| 公共收益分配 | 企业所得税申报口径 | 判断业委会/业主税负影响 |

### 数据流转

```
本SKILL：盘点公共收益来源 → 分类收入类型 → 确认合同条款
   ↓
税务专家：匹配税种 → 计算税额 → 运行风险扫描器（CAP-11/13）
   ↓
本SKILL：将税务结论整合进审计报告"税务处理审查"章节
```

## 四、与能耗专家的协作

| 场景 | 能耗专家输出 | 本SKILL如何使用 |
|------|------------|----------------|
| 公共能耗费用纳入公共收益 | 能耗费用合理性判定 | 判断成本扣除是否合理 |
| 充电桩场地租赁收入 | 充电服务费定价合规判定 | 判断公共资源经营收入合规性 |
| 公共区域照明费用 | 公共能耗分摊合规判定 | 判断公共收益支出合规性 |

---

## 五、与财务解读专家的协作

| 场景 | 财务解读输出 | 本SKILL如何使用 |
|------|------------|----------------|
| 公共收益分成台账分析 | 分成金额/比例/趋势/对标 | 判断分成比例是否异常 |
| 公共收益波动分析 | 波动原因识别（季节性/合同变更） | 判断是否存在舞弊 |
| 资源闲置评估 | 各资源收益对比/投资回报率 | 判断资源利用效率 |

---

## 六、与停车场经营专家（待建）的协作

停车场经营专家建成后，本SKILL的角色：
- **前置**：审阅停车场经营权合同（权属/期限/分成）
- **补充**：停车场收益纳入公共收益审查范围
- 详细分工待停车场专家v1.0发布后更新
