# 风险分级框架

## 风险等级定义

| 等级 | 标识 | 定义 | 处理要求 |
|---|---|---|---|
| **红色** | 🔴 | 违反法律强制性规定 | 必须整改，标注违法性质及法律后果 |
| **橙色** | 🟠 | 违反程序要求或存在重大合规隐患 | 限期整改，标注程序瑕疵及合规风险 |
| **黄色** | 🟡 | 存在瑕疵或风险倾向 | 建议优化，标注改进方向 |
| **绿色** | ✅ | 合规 | 明确标注"合规示范项" |

---

## 🔴 红色风险（触碰即标，无例外）

| 风险事项 | 法规依据 | 处置要求 |
|---|---|---|
| 公共收益归物业所有 | 《民法典》第282条 | 绝对无效，须返还 |
| 前期合同物业方分成>30%且无核定文件 | 各省物业管理条例 | 超出部分不得确认，须退还业主 |
| 双重收费（先扣成本再分成） | 禁止重复扣除 | 虚扣部分须退还 |
| 无凭证的"合理成本"扣除 | 《民法典》第282条 | 无凭证部分不得扣除，标注侵占 |
| 公共收益不入共管账户 | 各地共管账户规定 | 标注挪用风险，须限期纠正 |
| 连续3年以上未公示公共收益 | 《民法典》第943条 | 重大程序违法，标注严重失信 |
| 侵占公共收益金额达到法定追诉标准 | 《刑法》第271条 | 标注"涉嫌刑事违法，建议移送" |
| 公共资源经营未经业主大会授权 | 《民法典》第278条 | 程序违法，须补表决或终止经营 |
| 《民法典》施行后跨法履行合同仍按旧标准操作 | 《民法典》第282条 | 标注跨法履行不合规，须重新核算 |
| 对《民法典》施行前已存在、施行后持续经营的收益来源，仍未建立合规管理机制 | 《民法典》第282条、第943条 | 标注🔴长期未建立合规机制，须限期整改 |

---

## 🟠 橙色风险（限期整改）

| 风险事项 | 说明 |
|---|---|
| 未设共管账户（但资金未挪用） | 程序瑕疵，须限期设立 |
| 公示内容不完整 | 缺项少项，须补充公示 |
| 公示频次不足 | 未达法定频次要求 |
| 未建立公共收益合同台账 | 管理缺陷，须建立台账 |
| 合同到期后未及时续签 | 管理缺陷，须补签或重新招标 |
| 历史合同档案缺失 | 管理缺陷，须追补档案 |
| 权属争议（如人防车位） | 建议查阅当地判例确认 |

---

## 🟡 黄色风险（建议优化）

| 风险事项 | 说明 |
|---|---|
| 资源闲置（非故意） | 建议开发潜在收益 |
| 收入偏低但无侵占证据 | 建议市场对标、重新谈判 |
| 合同条款不够细化 | 建议在续签时完善 |
| 公示方式单一（仅张贴） | 建议增加线上公示渠道 |
| 合同金额与周边差异较大但无恶意 | 建议重新评估定价 |

---

## ✅ 合规示范项

对以下合规做法给予明确标注，形成正向引导：

- ✅ 已依法设立公共收益共管账户，实行双印鉴管理
- ✅ 按季度完整公示收支明细
- ✅ 前期合同物业方分成比例≤30%
- ✅ 成本扣除均有实际支出凭证
- ✅ 公共资源经营经业主大会授权
- ✅ 建立了完整的合同台账和财务档案
- ✅ 历史跨法履行业务已主动按《民法典》标准调整
