# 触发边界

## 什么时候启动这个Skill？

### ✅ 触发条件

| 触发场景 | 说明 |
|---|---|
| 业委会换届 | 新一届业委会需要对前任期间公共收益进行审计 |
| 业主集体质疑 | 超过20%业主联名对公共收益提出质疑 |
| 物业交接 | 新旧物业交接时需对公共收益进行清算 |
| 公共收益异常 | 收入骤降、长期未公示、分成异常等信号出现 |
| 年度例行审计 | 业委会或业主大会决定进行年度公共收益审计 |
| 合同到期前评估 | 公共收益相关合同到期，需评估续签条件 |

### ❌ 不适用场景

| 场景 | 说明 | 替代方案 |
|---|---|---|
| 审阅尚未签署的合同条款 | 属于合同审阅SKILL的范畴 | 使用合同审阅SKILL |
| 单个业主的个人物业纠纷 | 不涉及共有部分公共收益 | 咨询专业律师 |
| 开发商产权的商业部分 | 不归业主共有 | 不纳入审查范围，报告中标注排除 |
| 需要出具正式法律意见书 | 超出Skill边界 | 聘请律师出具 |
| 需要作出行政处罚决定 | 超出Skill边界 | 由行政机关作出 |

---

## 与合同审阅SKILL的边界

| 情况 | 由谁处理 |
|---|---|
| 合同尚未签署，审阅条款是否合法 | 合同审阅SKILL |
| 合同已经签署，审查实际执行是否合规 | 公共收益审查SKILL |
| 合同条款有问题，需要审查其实际影响 | 先合同审阅SKILL审查条款，再公共收益审查SKILL审查执行 |
| 合同完全没有公共收益条款，但存在实际业务 | 公共收益审查SKILL（走"无合同审资源"路径） |

---

## 资料要求

### 最低启动资料
- 小区名称和所在地（省份+城市）
- 物业服务合同（如有）

### 完整审查所需资料
- 物业服务合同（含历史合同）
- 全部公共收益相关经营合同（广告、停车、场地租赁、快递柜等）
- 近3-5年公共收益财务账目及银行流水
- 成本扣除明细及支出凭证
- 历次公示记录（含照片或截图）
- 业主大会关于公共资源经营的授权决议
- 业委会备案证明

---

## 审查边界

**审查范围包括：**
- 利用业主共有部分产生的收入（《民法典》第282条）
- 电梯广告、场地租赁、地面停车、快递柜、基站场地费等17种来源

**明确排除事项（须在报告中标注）：**
- 属于开发商产权的车位租金、商业租金
- 属于个人产权的地下停车位
- 物业公司自身的经营收入（不涉及共有部分）

---

## 证据标准

| 证据类型 | 要求 | 无证据时的处理 |
|---|---|---|
| 合同 | 原件或复印件 | 标注【合同缺失】 |
| 银行流水 | 银行出具的对账单 | 标注【证据不足，结论待确认】 |
| 发票 | 正规发票 | 标注【无发票，不确认】 |
| 记账凭证 | 财务入账凭证 | 标注【凭证缺失】 |
| 公示记录 | 照片或截图 + 时间戳 | 标注【公示记录缺失】 |
