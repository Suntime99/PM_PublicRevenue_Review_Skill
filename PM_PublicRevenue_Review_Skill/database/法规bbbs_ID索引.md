# 法规 bbbs ID 索引（flk.npc.gov.cn）

> 本文件收录物业公共收益审查相关法规在国家法律法规数据库（flk.npc.gov.cn）中的 **bbbs ID**，用于快速定位法规详情页。

## 使用说明

详情页URL格式：
```
https://flk.npc.gov.cn/detail?id={bbbs}
```

批量下载工具：
```bash
python tools/legal_fulltext_fetcher.py --bbbs {bbbs} --name "法规名" --output database/national/law/法规名_全文.txt
```
