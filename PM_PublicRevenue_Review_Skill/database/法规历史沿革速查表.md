# 法规历史沿革速查表（历次版本 bbbs ID）

> 本表收录物业公共收益审查相关法规在 flk.npc.gov.cn 的**历次修订版本 bbbs ID**。
> 用于 **P13 历史业务与跨法履行审查**：判断某年份的合同/行为应适用哪个版本的法规。
>
> 数据来源：flk `flfgDetails` 接口的 `lsyg`（历次沿革）字段，2026-10-11 核验。
> 结构化数据：`data/law_history.json`

## 使用说明

访问某历史版本原文：
```
https://flk.npc.gov.cn/detail?id={bbbs}
```

下载某历史版本 Word 原件：
```bash
python tools/legal_fulltext_fetcher.py --bbbs {bbbs} --name "法规名_年份" --output database/national/law/法规名_年份_全文.txt
```

## 审查应用场景

1. **历史合同审查**：合同签订于2020年 → 查2020年有效的条例版本（如上海2020-12-30版）
2. **跨法履行**：行为持续跨多个版本 → 分段适用各版本（P13）
3. **案例回溯**：裁判文书引用旧版条例 → 用对应版本核对原文
4. **新旧对比**：下载相邻版本全文，diff关键条款变化
5. **省级/市级法规版本**：直接查 `法规完整全文覆盖清单.md` 中对应文件的题注（含完整修订沿革）
