# 法规全文数据库（database/）

> 本数据库由「数据采集工具链SKILL」于2026-10-10建成，共 **80个法规数据文件 + 1个索引README（81个文件）**。
> 法规元数据（bbbs编号、制定机关、公布日期、施行日期、时效状态）已通过**国家法律法规数据库（flk.npc.gov.cn）API**核验。
> 本数据库与 `data/` 目录下的JSON速查库互补：JSON提供结构化参数检索，本目录提供法规原文与条款速查。

---

## ⚠️ 数据口径说明（2026-10-12盘点更新）

本目录文件分两类，**审查引用时务必区分**：

| 类型 | 含义 | 数量 |
|---|---|---|
| **完整全文版**（`*_全文_完整版.txt`） | 从官方原件解析的全量条文，**可精确引用原文条款** | **36部**（见 [法规完整全文覆盖清单.md](法规完整全文覆盖清单.md)） |
| **核心条款节选**（`*_全文.txt` 等） | 公开渠道核验后的要点整理，**无条文号/无原文**，仅供参数速查，不可作审计底稿引用 | 其余文件 |

- 省级目录下31省条例文件多数为**约1KB的节选**（含关键参数速查表），已有14省有完整全文。
- 城市级目录下多数文件为节选，仅10个城市有完整全文。
- **审查高频省份/城市**（广东、浙江、江苏、上海、北京、四川、福建、河南、湖北、江西、湖南、安徽、黑龙江、西藏 + 南京、杭州、成都、武汉、西安、无锡等）**已有完整全文**，可直接引用。
- 完整缺口清单见 [缺口盘点报告_法规制度判例.md](缺口盘点报告_法规制度判例.md)。

## 使用建议

1. **审查启动时**：先读 `policy-knowledge/公共收益政策知识库.md` 建立整体框架
2. **地域法规锁定时**：查 `provincial/{省份}/` + `municipal/{城市}/` 对应文件
3. **法规原文引用时**：从 `national/` 对应文件复制条款原文
4. **案例引用时**：`policy-knowledge/典型案例裁判规则汇总.md` + `data/case_law.json`
