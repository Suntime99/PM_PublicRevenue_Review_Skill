# 黑龙江省物业管理条例（公共收益相关条款节选）

- **来源**: 国家法律法规数据库/黑龙江省人大常委会
- **时效状态**: ✅ 现行有效
- **效力层级**: 地方性法规
- **审查应用**: P2、P5、P6、P7、P9

## 核心规定速查

| 审查参数 | 黑龙江省规定 |
|---|---|
| **管理成本上限** | 协商确定 |
| **前期合同物业方分成上限** | 协商确定 |
| **公示频次** | 每半年至少1次 |
| **共管账户** | 专户管理、独立核算、定期公布；严禁个人名义存储 |
| **特别规定** | 2026年推行96项物业服务收费定额标准（全国首创） |

## 相关要点（审查应用）

- 黑龙江省住宅物业管理条例明确公共收益归业主共有；
- 2026年推行96项物业服务收费定额标准（全国首创）；
- 住宅小区公共收益管理通知（2025-11-28）：专户管理、独立核算、定期公布；严禁个人名义存储。
