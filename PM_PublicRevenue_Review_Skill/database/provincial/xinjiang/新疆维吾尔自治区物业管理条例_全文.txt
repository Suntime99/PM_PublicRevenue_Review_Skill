# 新疆维吾尔自治区物业管理条例（公共收益相关条款节选）

- **来源**: 国家法律法规数据库/新疆维吾尔自治区人大常委会
- **时效状态**: ✅ 现行有效
- **效力层级**: 地方性法规
- **审查应用**: P2、P5、P6、P7、P9

## 核心规定速查

| 审查参数 | 新疆维吾尔自治区规定 |
|---|---|
| **管理成本上限** | 协商确定 |
| **前期合同物业方分成上限** | 协商确定 |
| **公示频次** | 每半年至少1次 |
| **共管账户** | 非强制 |
| **特别规定** | 乌鲁木齐万泰阳光城案例：230万元公共收益分红 |

## 相关要点（审查应用）

- 新疆维吾尔自治区物业管理条例明确：利用物业共用部位、共用设施设备进行经营的所得收益，在扣除合理成本之后，属于业主共有；
- 征求意见稿（2026年2-3月）推进公共收益专户专管；
- 乌鲁木齐万泰阳光城案例：230万元公共收益分红，专户专管，三方监督。
