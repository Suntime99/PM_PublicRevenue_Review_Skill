# 公共收益政策知识库（扩充版）

> 本文件系统梳理公共收益审查涉及的政策知识，作为各数据文件的索引和速查入口。

## 一、公共收益的定义与范围

### 什么是公共收益？

公共收益是指利用业主共有部分产生的收入，在扣除合理成本之后，属于业主共有的部分。依据《民法典》第282条。

### 常见公共收益来源（8类以上）

1. **电梯广告**（框架广告、视频广告）
2. **外墙广告**（楼顶广告牌、墙体广告）
3. **公共停车位**（地面规划外车位、临时停车）
4. **场地租赁**（快递柜、自动售货机、售水机、充电桩）
5. **通信基站**（运营商基站租金）
6. **公共设施经营**（泳池、健身房、会所）
7. **人防车位**（收益归属有争议，各地规则不同）
8. **物业用房出租**（业主共有的物业用房对外出租）

## 二、法律框架

### 法律层级

```
宪法
├── 法律：民法典（第271-287、937-950条）、物业管理条例、人民防空法、价格法、刑法
├── 司法解释：物业服务纠纷解释、建筑物区分所有权解释、时间效力规定
├── 行政法规：物业管理条例（国务院令第698号修订）
├── 部门规章：物业服务收费管理办法、物业承接查验办法、住宅专项维修资金管理办法
└── 地方性法规：31省物业管理条例
    └── 地市级细则：各市物业管理条例/公共收益管理办法
```

## 三、核心审查参数

### 管理成本上限

| 地区 | 上限 |
|---|---|
| 广东省 | ≤30% |
| 浙江省（多数地市） | ≤30% |
| 广州市 | ≤30% |
| 铜陵市 | ≤30% |
| 其他省份 | 协商确定/各地市规定 |

### 公示频次

| 地区 | 频次 |
|---|---|
| 广东省、北京市、深圳市、广州市 | 每季度至少1次 |
| 福建省 | 合同签订7天内公示≥30天 |
| 河南省 | 每季度≥30个工作日 |
| 海南省 | 每季度≥30日 |
| 上海市、江苏省、浙江省等 | 每半年至少1次 |
| 扬州市 | 每年至少1次≥1个月 |

### 共管账户要求

- **强制**：广东、深圳、广州、黑龙江（专户管理）、福建（专户存储）、河南（专户存储）
- **监管账户**：上海
- **建议**：北京、浙江
- **非强制**：其余省份

## 四、审查红线速查

| 红线 | 依据 |
|---|---|
| 公共收益归物业所有 → 绝对无效 | 《民法典》第282条 |
| 前期合同物业方分成>30%且无核定文件 | 各省条例 |
| 无凭证的"合理成本"扣除 | 《民法典》第282条；区分所有权解释第14条 |
| 公共收益不入共管账户 | 各地共管账户规定 |
| 连续3年以上未公示 | 《民法典》第943条 |
| 侵占金额达6万元 → 涉嫌刑事 | 《刑法》第271条 |

## 五、人防车位收益归属规则

| 地区 | 规则 |
|---|---|
| 全国一般规则 | 投资者使用管理，收益归投资者（《人民防空法》第5条） |
| 苏州/无锡 | 成本转嫁推定规则：无法证明未计入房价的，推定归业主 |
| 新疆/安徽/江苏 | 禁止出售，归投资者所有，租赁不超过3年 |
| 江西/湖南 | 使用权人享有收益，可转让使用权 |
