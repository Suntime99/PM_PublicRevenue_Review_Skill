# 司法解释物业相关条款详解

## 一、《最高人民法院关于审理物业服务纠纷案件适用法律若干问题的解释》（法释〔2020〕17号）

| 条款 | 内容 | 审查应用 |
|---|---|---|
| 第1条 | 前期物业服务合同、业委会与业主大会选聘的物业服务合同，对业主具有法律约束力 | P10、P13 |
| 第2条 | 将全部物业服务转委托给第三人 → 合同无效 | P10 |
| 第3条 | 擅自扩大收费范围、提高收费标准、重复收费 → 业主可抗辩并要求退还 | P5、P6 |
| 第4条 | 物业未按约提供服务的，业主可抗辩 | P6 |

## 二、《最高人民法院关于审理建筑物区分所有权纠纷案件适用法律若干问题的解释》（法释〔2009〕7号，2020年修正）

| 条款 | 内容 | 审查应用 |
|---|---|---|
| **第3条** | 共有部分的扩大解释：基础、承重结构、外墙、屋顶、楼梯、电梯厅、走廊、通道、避难层、设备层等 | P1、P2 |
| **第7条** | 改变共有部分用途、利用共有部分从事经营性活动 → 属于"其他重大事项"，须业主共同决定 | P10 |
| **第13条** | 业主知情权：可请求公布/查阅维修资金、管理规约、物业服务合同、共有部分使用和收益情况、车位处分情况 | P9 |
| **第14条** | 擅自占用/处分共有部分 → 权利人可请求返还扣除合理成本后的收益；**行为人对成本支出及合理性承担举证责任** | P6、P8 |

## 三、《最高人民法院关于适用〈中华人民共和国民法典〉时间效力的若干规定》（法释〔2020〕15号）

| 条款 | 内容 | 审查应用 |
|---|---|---|
| 第1条第2款 | 民法典施行前的法律事实 → 适用当时的法律（法不溯及既往） | P13（阶段一） |
| 第1条第3款 | 民法典施行前的法律事实持续至施行后 → 适用民法典（跨法履行） | P13（阶段二） |
| 第2条 | 有利追溯原则 | P13 |
