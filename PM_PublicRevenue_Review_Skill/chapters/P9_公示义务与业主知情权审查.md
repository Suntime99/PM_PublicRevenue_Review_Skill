# P9 公示义务与业主知情权审查

## 模块定位

| 属性 | 说明 |
|---|---|
| 所属层次 | 第三层：有业务，审业务 / 第四层：看当前鉴未来 |
| 核心问题 | 公共收益是否按规定公示？业主知情权是否得到保障？ |
| 法规依据 | 《民法典》第943条（信息公开义务） |

---

## 一、公示义务的法律依据

### 《民法典》第943条

> "物业服务人应当定期将服务的事项、负责人员、质量要求、收费项目、收费标准、履行情况，以及维修资金使用情况、业主共有部分的经营与收益情况等以合理方式向业主公开并向业主大会、业主委员会报告。"

**核心要求：**
- 定期公开
- 公开内容完整（含共有部分经营与收益情况）
- 以合理方式公开
- 向业主大会、业委会报告

---

## 二、公示审查要点

### 2.1 公示频次审查

| 地域 | 要求频次 | 审查标准 |
|---|---|---|
| 广东省 | 每季度 | 一年至少4次 |
| 浙江省 | 每半年 | 一年至少2次 |
| 上海市 | 每半年 | 一年至少2次 |
| 北京市 | 每季度 | 一年至少4次 |
| 各地 | 以当地规定为准 | — |

**不合规情形：**
- 未按法定频次公示 → 🟠
- 连续3年以上未公示 → 🔴

### 2.2 公示内容审查

| 内容项 | 是否必需 | 说明 |
|---|---|---|
| 公共收益总收入 | ✅ 必需 | 各项收入合计 |
| 各项收入明细 | ✅ 必需 | 按来源分类列示 |
| 物业方分成分成金额 | ✅ 必需 | 含分成比例 |
| 业主方实收金额 | ✅ 必需 | 业主实际收到金额 |
| 成本扣除明细 | ✅ 必需 | 逐项列示成本项目 |
| 资金结余 | ✅ 必需 | 账户余额 |
| 共管账户收支流水 | 🟡 建议 | 最好附上 |

**不合规情形：**
- 公示内容不完整（缺项） → 🟡
- 公示内容严重缺失（无具体金额） → 🟠

### 2.3 公示方式审查

| 方式 | 合规性 | 说明 |
|---|---|---|
| 小区公告栏张贴 | ✅ 合规 | 基础方式 |
| 业主微信群发布 | ✅ 合规 | 信息化方式 |
| 物业APP发布 | ✅ 合规 | 需确保业主可查阅 |
| 未公示 | 🔴 不合规 | 严重违规 |

---

## 三、历史公示记录核查

### 3.1 核查清单

- [ ] 近3年是否每年都有公示？
- [ ] 公示频次是否达到法定要求？
- [ ] 公示内容是否完整（含收入/成本/分成/结余）？
- [ ] 公示方式是否合理（业主可查阅）？
- [ ] 是否有公示记录存档（照片/截图+时间戳）？

### 3.2 历史公示缺失的处理

| 情况 | 处理方式 |
|---|---|
| 从未公示 | 🔴 标注"长期未公示公共收益，存在重大信息不透明及资金被挪用的高度嫌疑" |
| 公示内容不完整 | 🟠 标注"公示内容不完整，建议补充" |
| 公示记录缺失 | 🟡 标注"公示记录缺失，无法核实是否按期公示" |

---

## 四、业主知情权保障审查

### 4.1 业主权利

| 权利 | 依据 | 审查要点 |
|---|---|---|
| 查阅权 | 《民法典》第943条 | 业主是否有权查阅原始合同和账目？ |
| 复制权 | 《民法典》第943条 | 业主是否有权复制相关资料？ |
| 审计权 | 法理 | 业主是否有权委托第三方审计？ |

### 4.2 物业配合度评估

| 物业态度 | 评估结论 |
|---|---|
| 主动公开、积极配合 | ✅ 合规 |
| 被动公开、配合有限 | 🟡 需改善 |
| 拒绝公开、阻挠查阅 | 🔴 严重违规 |
