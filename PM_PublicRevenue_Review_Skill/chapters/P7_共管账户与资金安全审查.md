# P7 共管账户与资金安全审查

## 模块定位

| 属性 | 说明 |
|---|---|
| 所属层次 | 审业务 + 看当前鉴未来 |
| 前置依赖 | P6（已完成成本审查） |
| 核心目标 | 审查公共收益资金是否安全、是否被挪用 |

---

## 一、共管账户的法律要求

### 依据

| 依据 | 要求 |
|---|---|
| 《民法典》第943条 | 物业应公开公共收益收支情况 |
| 各地物业管理条例 | 多数地区要求设立共管账户 |
| 广东省 | 共管账户强制要求 |

### 共管账户的特征

| 特征 | 说明 |
|---|---|
| 账户性质 | 银行对公账户 |
| 账户名称 | 小区公共收益共管账户 |
| 印鉴管理 | 双印鉴（业委会+物业公司） |
| 资金归属 | 业主共有资金 |

---

## 二、账户类型审查

### 2.1 账户类型判定

| 账户类型 | 合规性 | 风险等级 |
|---|---|---|
| 共管账户（双印鉴） | ✅ 合规 | 低风险 |
| 物业公司内部单独列账 | 🟠 程序瑕疵 | 中风险 |
| 物业公司账户混同 | 🔴 不合规 | 高风险 |
| 私人账户收款 | 🔴 严重不合规 | 极高风险 |

### 2.2 审查要点

- [ ] 公共收益是否进入共管账户？
- [ ] 共管账户是否实行双印鉴管理？
- [ ] 账户资金是否独立核算？
- [ ] 账户收支是否按期公示？
- [ ] 是否存在个人账户代收情况？

---

## 三、资金流向追踪

### 3.1 资金流向全链条

收益来源 → 收款账户 → 分配 → 使用 → 结余

### 3.2 追踪要点

| 环节 | 审查要点 | 异常信号 |
|---|---|---|
| 来源 | 收入是否全部入账 | 现金收款、个人收款 |
| 收款账户 | 是否进入共管账户 | 进入物业公司账户 |
| 分配 | 是否按合同约定分配 | 拖欠、不足额 |
| 使用 | 业主方收益使用是否合规 | 未经业主大会使用 |
| 结余 | 是否有完整结余记录 | 账实不符 |

### 3.3 挪用风险信号

| 信号 | 风险等级 | 说明 |
|---|---|---|
| 公共收益与物业收入混同 | 🔴 | 无法区分，资金可能被挪用 |
| 现金收款不入账 | 🔴 | 收入被隐匿 |
| 长期拖欠业主方分成款 | 🔴 | 资金被挪用 |
| 无独立账户 | 🟠 | 资金安全无保障 |
| 账户余额与账面余额不符 | 🔴 | 账实不符，资金可能被挪用 |
