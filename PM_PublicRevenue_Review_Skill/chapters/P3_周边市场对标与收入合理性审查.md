# P3 周边市场对标与收入合理性审查

## 模块定位

| 属性 | 说明 |
|---|---|
| 所属层次 | 审业务 + 看当前鉴未来 |
| 前置依赖 | P1、P2（已完成资源盘点和权属判定） |
| 核心目标 | 通过横向对比判断本小区公共收益是否合理 |

## 二、周边小区对标操作指引

### 2.1 对标小区选取标准

- 同区域（同一街道/商圈半径1-3公里内）
- 同类型（相似建筑年代、相似规模、相似档次）
- 同业态（纯住宅/商住混合）

### 2.2 对标数据收集方法

| 方法 | 说明 | 注意事项 |
|---|---|---|
| 业主间询问 | 向周边小区业主了解大致收益水平 | 数据可能不精确，仅供参考 |
| 物业行业交流 | 通过物业行业会议/微信群了解 | 需验证数据来源 |
| 公开招标信息 | 部分地区要求公共资源经营公开招标 | 较可靠的数据来源 |
| 审计行业经验 | 第三方审计机构有行业数据库 | 可靠性较高 |
| 公开判例 | 法院案例中披露的收益数据 | 精确但样本有限 |

### 2.3 差异分析

| 本小区与对标小区差异 | 可能原因 | 关注点 |
|---|---|---|
| 收入显著偏低（<对标70%） | 合同定价偏低/收入未入账/资源闲置 | 深查 |
| 收入显著偏高（>对标130%） | 资源价值更高/存在经营性优势 | 正常但需关注 |
| 收入与对标持平 | 基本合理 | 可接受 |

---

## 三、收入合理性判断标准

### 3.1 正常范围

- 单项收入在行业均价±30%范围内：✅ 合理
- 如有充分理由（如位置优越/配套成熟）高于均价30%：🟡 需说明，标注"偏高但有合理理由"

### 3.2 异常信号

| 信号 | 风险等级 | 处理建议 |
|---|---|---|
| 单项收入低于均价50% | 🟠 | 深入调查原因，是否存在低价合同/截留 |
| 某项收益来源完全无收入但存在资源 | 🔴 | 调查是否被无偿占用或收入被隐匿 |
| 合同金额与周边差异极大（>100%） | 🔴 | 调查是否存在关联交易或利益输送 |

---

## 四、注意事项

1. **对标数据须说明来源**，不得编造数据
2. **考虑年份差异**，对标数据应与审查年份接近
3. **城市差异巨大**，一线城市与三四线城市参照值不同
4. **差异不等于违规**，偏低可能是客观因素导致，偏高可能是资源禀赋好
5. **结合历史趋势分析**（P4）综合判断
