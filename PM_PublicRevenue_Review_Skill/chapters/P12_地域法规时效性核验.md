## 七、反向推演：对方会怎么攻我们的法规引用？

### 7.1 法规引用常见攻击点

| 攻击方式 | 具体话术 | 我方应对 |
|---|---|---|
| **法规已废止** | "你们引用的条例2020年就废止了，现在用的是2023年新版" | 核查法规时效性，引用最新有效版本 |
| **地方不适用** | "你们是广东的规定，但我们项目在浙江，不能用" | 确认项目所在地，适用当地法规 |
| **条款解读不同** | "这条你们理解错了，应该是……" | 引用官方释义、司法解释、典型案例 |
| **上位法优先** | "地方规定跟民法典冲突，应该以民法典为准" | 确认地方法规不与上位法冲突 |
| **历史合同不适用新法** | "合同签订于2015年，不能用2021年的民法典" | 区分阶段一/阶段二审查，跨法履行部分适用新法 |

### 7.2 法规引用检查清单

- [ ] 引用的法规是否为**现行有效**版本？
- [ ] 引用的条款是否为**最新修正**后的条文？
- [ ] 引用的地方法规是否**适用于项目所在地**？
- [ ] 引用的法规是否与**上位法冲突**？
- [ ] 对于历史合同，是否已**区分法律适用阶段**？
