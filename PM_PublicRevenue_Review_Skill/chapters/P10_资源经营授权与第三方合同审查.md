# P10 资源经营授权与第三方合同审查

## 模块定位

| 属性 | 说明 |
|---|---|
| 所属层次 | 第一层：有合同，审合同 / 第三层：有业务，审业务 |
| 核心问题 | 公共资源经营是否经过合法程序？第三方合同是否合规？ |
| 法规依据 | 《民法典》第278条（业主共同决定）；《物业管理条例》第54条 |

---

## 一、授权程序审查

### 1.1 法律依据

| 条款 | 内容 | 要求 |
|---|---|---|
| 《民法典》第278条 | 业主共同决定事项 | 利用共有部分从事经营活动须经业主大会表决 |
| 《物业管理条例》第54条 | 利用共用部位进行经营 | 须经业主大会同意 |

### 1.2 授权程序审查要点

| 审查项 | 合规标准 | 不合规情形 |
|---|---|---|
| 是否经业主大会表决 | 有会议决议 | 无决议 → 🔴 |
| 表决程序是否合法 | 双2/3参与，双3/4同意 | 程序违法 → 🔴 |
| 是否在有效期内 | 决议未过期 | 过期 → 🟠 |
| 授权范围是否明确 | 明确经营内容和期限 | 概括性授权 → 🟡 |

### 1.3 特殊情况

| 情况 | 处理方式 |
|---|---|
| 前期物业服务合同中已约定经营权 | 审查是否经过业主大会追认 |
| 物业代签第三方合同 | 审查是否有业主大会授权 |
| 业委会未成立 | 依据前期物业服务合同约定；建议尽快成立业委会 |

---

## 二、第三方合同审查要点

### 2.1 签约主体合法性

| 审查项 | 合规标准 | 不合规情形 |
|---|---|---|
| 签约主体 | 业主大会或授权业委会 | 物业单独签约 → 🟠 |
| 第三方资质 | 合法注册经营 | 无资质 → 🔴 |
| 合同签章 | 有效公章或签字 | 无章/代签 → 🔴 |

### 2.2 合同内容合规性

| 审查项 | 合规标准 | 不合规情形 |
|---|---|---|
| 经营内容 | 在业主大会授权范围内 | 超范围 → 🔴 |
| 合同期限 | 通常不超过3-5年 | 过长（>10年） → 🟠 |
| 合同金额 | 市场公允价格 | 明显偏低 → 🟠 |
| 分成条款 | 符合法定上限 | 超过上限 → 🔴 |

### 2.3 合同签约流程合规性

标准流程：资源经营计划 → 业主大会表决 → 授权业委会执行 → 业委会与第三方签约 → 合同备案

| 环节 | 合规标准 | 不合规情形 |
|---|---|---|
| 计划 | 有书面经营方案 | 无方案直接签约 → 🟠 |
| 表决 | 双2/3参与，双3/4同意 | 未经表决 → 🔴 |
| 签约 | 业委会签约或授权物业签约 | 物业私自签约 → 🔴 |
| 备案 | 合同存档 | 无存档 → 🟡 |

---

## 三、输出物

- 《公共资源经营授权合规审查报告》
- 《第三方合同合法性审查表》
- 《违规签约事项清单》
