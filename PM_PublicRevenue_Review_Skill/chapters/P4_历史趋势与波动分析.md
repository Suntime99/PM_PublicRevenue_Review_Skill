# P4 历史趋势与波动分析

## 模块定位

| 属性 | 说明 |
|---|---|
| 所属层次 | 审业务 + 看当前鉴未来 |
| 前置依赖 | P3（已完成市场对标） |
| 核心目标 | 通过3-5年历史数据分析识别异常波动 |
| 法规依据 | 《民法典》第943条（公示义务长期核查） |

---

## 一、合同台账建立

### 1.1 合同台账字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 合同编号 | 唯一标识 | HT-2020-001 |
| 签约方 | 甲方/乙方/丙方 | 甲方：业委会；乙方：XX广告公司 |
| 经营内容 | 具体经营项目 | 电梯广告 |
| 合同期限 | 起止日期 | 2020.01.01 - 2022.12.31 |
| 合同金额 | 年收入/总金额 | 10万元/年 |
| 分成比例 | 物业方分成比例 | 30% |
| 结算周期 | 按月/按季/按年 | 按季 |
| 实际收入 | 年度实收金额 | 9.8万元（2020年） |
| 实际分成 | 物业方实收分成 | 2.94万元 |
| 备注 | 特别事项 | 合同到期未续签 |

### 1.2 合同台账审查要点

- [ ] 所有公共收益合同是否全部登记？
- [ ] 合同编号是否连续、无遗漏？
- [ ] 合同金额与实收金额是否一致？
- [ ] 合同到期后是否续签或终止？
- [ ] 是否存在"无合同"但实际经营的项目？

## 二、历史收入趋势分析

### 2.1 统计维度

| 维度 | 说明 |
|---|---|
| 按年份 | 2019、2020、2021、2022、2023 |
| 按来源 | 电梯广告、停车费、场地租赁、快递柜、基站等 |
| 按季度 | 识别季节性波动 |

### 2.2 趋势分析方法

| 方法 | 操作 | 异常信号 |
|---|---|---|
| 年度同比 | 本年 vs 上年 | 波动>±30%需关注 |
| 来源占比 | 各来源占总收入比例 | 某项占比骤降需关注 |
| 3年复合增长率 | CAGR计算 | 负增长且周边上涨需预警 |

### 2.3 异常波动信号

| 信号 | 可能原因 | 风险等级 |
|---|---|---|
| 某单项收入突然归零 | 合同到期未续签/收入转移/资源闲置 | 🔴 |
| 总收入连续3年下滑 | 经营不善/收入截留/合同定价偏低 | 🟠 |
| 某单项收入骤降>50% | 合同变更/收入被转移 | 🟠 |
| 收入稳定但周边上涨 | 本小区合同锁价/收入未调整 | 🟡 |

## 三、历年分成趋势分析

| 分析维度 | 关注点 | 异常信号 |
|---|---|---|
| 物业方分成比例变化 | 是否保持稳定 | 比例突然上升需关注 |
| 业主方实收金额变化 | 是否与合同一致 | 长期拖欠或不足额支付 |
| 结算周期变化 | 是否按时结算 | 结算周期延长需关注 |
