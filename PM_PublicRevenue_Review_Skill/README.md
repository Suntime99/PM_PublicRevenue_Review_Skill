# 物业公共收益审查专家 —— 快速入门

## 这个Skill是做什么的？

这是一个专门用于审查住宅小区公共收益的AI工具包。它帮助业委会、业主代表、物业内审人员系统性地核查：

- 小区有哪些公共资源？哪些在产生收益，哪些在闲置？
- 公共收益是否被合法、合规地收取、分配和管理？
- 是否存在资金被侵占或挪用的风险？
- 当前的公共收益管理是否合法合规？未来如何改进？

## 什么时候使用这个Skill？

| 场景 | 说明 |
|---|---|
| 业委会换届审计 | 新一届业委会需要对前任期间的公共收益进行全面审查 |
| 业主对公共收益有重大质疑 | 业主发现公共收益异常，要求启动审查 |
| 物业公司更换交接 | 新旧物业交接时，需要对公共收益进行清算审计 |
| 第三方审计机构进场 | 作为审计工作的底稿和操作指引 |
| 业主大会决策前 | 需要对公共收益状况摸底，为决策提供依据 |

## 如何开始使用？

**第一步：确认项目所在地**

> 公共收益审查高度依赖地方政策。启动审查前，必须先确认小区所在省份和城市。

**第二步：选择指令**

> 根据审查需求选择对应的预设指令（6条之一），输入给AI。

**第三步：提供基础资料**

> 向AI提供合同、财务账目、银行流水、公示记录等基础资料。

**第四步：获取输出物**

> AI根据指令和资料，输出五件套（对抗性场景另加第6件《对手视角弱点与应对策略报告》）：审计报告、审查清单、分成台账、资源台账、风险清单、弱点分析。

## 6条预设指令速查

| 指令 | 一句话说明 | 最快出结果时间 |
|---|---|---|
| ① 全面审查 | 首次系统性审计，出完整报告 | 需提供完整资料 |
| ② 分成审计 | 聚焦"分了多少、怎么分的" | 需提供合同+分成记录 |
| ③ 资金安全审计 | 聚焦"钱有没有被挪用" | 需提供银行流水+账户信息 |
| ④ 快速扫描 | 3分钟判断要不要深度审查 | 只需提供小区基本信息 |
| ⑤ 成本审查 | 聚焦"管理成本扣得合不合理" | 需提供成本明细+凭证 |
| ⑥ 授权审查 | 聚焦"经营有没有经过合法程序" | 需提供合同+业主大会决议 |

## Skill核心理念

> **有合同审合同，无合同审资源；有业务审业务，看当前鉴未来。**
> **历史合同看"当时"合法性，当前履行看"现在"合规性。**

## 注意事项

1. **审查结论须以书面证据为依据**，不得仅凭口头陈述
2. **地方政策差异极大**，审查前必须先确认项目所在地
3. **历史合同不翻旧账定罪**，分阶段审查，重在当前合规
4. **最终输出物均为分析报告**，不构成法律意见书或行政处罚决定
